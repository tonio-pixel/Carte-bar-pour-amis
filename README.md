# 📍 Meet at the Bar - Carte Interactive

Une application web interactive conçue pour calculer le point de rendez-vous idéal pour un groupe. En saisissant jusqu'à 5 adresses différentes, le système calcule un point de convergence géographique et suggère des établissements pertinents à mi-chemin (comme le futur bar d'application Le Pixel ou d'autres concepts axés sur la mixologie).

## 🚀 Voir l'application en direct
[👉 Cliquez ici pour ouvrir la carte interactive](https://tonio-pixel.github.io/Carte-bar-pour-amis/)

## ⚙️ Fonctionnalités
* **Géocodage multiple :** Transformation instantanée des adresses postales en coordonnées GPS.
* **Calcul de convergence :** Détermination du centre exact pour minimiser le trajet de chaque participant.
* **Affichage ciblé :** Pop-ups interactifs affichant la typologie de l'établissement (ex: options No/Low ABV), le prix moyen de la pinte et les événements en direct.
* **Mode sombre :** Interface visuelle optimisée pour le monde de la restauration et de la nuit.

## 🛠️ Technologies Utilisées
* **Interface UI/UX :** HTML5, JavaScript, Tailwind CSS.
* **Cartographie :** Bibliothèque Leaflet.js.
* **Open Data :** API publique Nominatim (OpenStreetMap) pour le géocodage et serveur CartoDB Dark Matter pour le fond de carte.
