# 🍻 Meet at the Bar

> Trouvez le bar parfait au point d'équidistance de votre groupe d'amis.

## 📖 Description

**Meet at the Bar** est une application web single-page (SPA) qui permet à un groupe
de 2 à 5 personnes de saisir leurs adresses de départ et leur moyen de transport
respectif. L'application calcule un **point de rendez-vous équitable** (barycentre
pondéré) et affiche les **3 meilleurs bars** les plus proches de ce point, directement
sur une carte interactive en mode sombre.

## 🚀 Déploiement

- Hébergé sur **GitHub Pages** : https://tonio-pixel.github.io/Carte-bar-pour-amis/
- Développé sur mobile via l'éditeur **Acode**
- 100% statique (HTML/CSS/JS), aucune clé API, aucun backend
